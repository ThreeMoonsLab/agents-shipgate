`038bdb4650d45d9c81996f60d33781b5671bfb57f006233f80e74db8a7377d33`.
Its contract is **40**; the source checkout is contract **41**. Package
version alone does not identify the newer source behavior. Published 1.0.0
metadata remains historical, and this source change also does not retroactively
alter the published 1.1.0 wheel.

The wheel was installed with `--no-deps` into a separate temporary target,
using Python 3.12 and dependencies from the existing project virtualenv.
Import-path inspection confirmed the temporary wheel installation was loaded,
not checkout source. This is not a clean dependency-install trial.

`.claude/settings.json`, with this change between two commits:

```text
base: permissions.allow = ["Bash(npm test *)"]
head: permissions.allow = ["Bash(npm *)"]
```

```sh

```

There was no `shipgate.yaml`, authored policy, saved baseline or loaded skill.

the actual before/after, a coverage section identifying the settings file,
and a review question. It explicitly described static configuration and
implied no verdict. JSON reported `comparison_status: comparable`.

As a negative control, malformed head settings yielded
`comparison_status: incomparable`, naming the parse failure. Advisory exit
code 0 did not establish a covered no-change result. The original settings
bytes were restored after this control.

This exercises the entry promised by the descriptions. It establishes no
runtime reach, reviewer comprehension, task selection, retention, ranking or
